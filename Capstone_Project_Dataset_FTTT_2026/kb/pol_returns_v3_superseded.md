# Returns policy (version 3)

> This version was replaced by version 4 on 1 August 2026. It still applies only to electronics delivered before 1 August 2026.

## [RETv3-2] Return windows by category
| Category | Return window |
| --- | --- |
| Electronics and accessories | 10 days |
| Clothing, footwear and bags | 15 days |
| Home, kitchen and furniture | 10 days |
| Beauty and personal care (unopened) | 7 days |
| Books and stationery | 10 days |
| Grocery, innerwear, gift cards | Not returnable |

## [RETv3-6] Reverse pickup
Reverse pickup is free for all returns.
