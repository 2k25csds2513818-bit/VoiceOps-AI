# Coupons and offers

## [CPN-1] One coupon per order
Only 1 coupon can be applied per order. Coupons cannot be combined, added after the order is placed, or exchanged for cash.

## [CPN-2] Expired or failed coupons
A coupon that was valid but failed to apply because of a technical error can be re-issued once by support if the order was placed within the coupon's validity. Coupons that had already expired cannot be re-issued.

## [CPN-3] Returns and coupons
See REF-4 in the Refunds policy.
