# Tracking your order

## [TRK-1] Order statuses
| Status shown | What it means |
| --- | --- |
| Placed | Payment confirmed, waiting to be packed |
| Packed | Packed at the warehouse, waiting for courier pickup |
| Shipped | With the courier, on the way |
| Out for delivery | With the delivery executive today |
| Delivery attempted | The courier could not deliver; see DEL-3 |
| Delivered | Handed over at the address |
| Returned to origin (RTO) | Could not be delivered and is going back to the warehouse; prepaid refunds follow REF-1 |
| Cancelled | Cancelled before shipping |

## [TRK-2] Delivered but not received
If an order shows Delivered but the customer has not received it, check with family, neighbours or the building security, then report it within 48 hours as a missing item under DWM-1.
